# Downloadable study material

- `analytical_code_guide.pdf`: complete theory and line commentary for the
  original analytical project. The Streamlit interface was added afterward.
- `example_project_report.pdf`: original illustrative three-case analytical
  report. It is a fixed example and does not update when a visitor edits inputs.

The online calculator generates current CSV/JSON/PNG downloads in memory.
No API keys, account credentials or visitor-specific files belong in this folder.
